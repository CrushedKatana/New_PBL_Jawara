# Panduan Cepat Admin Dashboard

## Cara Login sebagai Admin

1. Jalankan aplikasi Jawara Marketplace
2. Di halaman login, scroll ke bawah ke bagian "Demo Mode - Login Cepat"
3. Klik tombol **"Admin"**
4. Aplikasi akan otomatis membuka Admin Dashboard

## Fitur-Fitur Utama

### 📊 Dashboard
- Lihat statistik global (Total Warga, Produk, Transaksi, GMV)
- Monitor performa setiap RT
- Cek status sistem (PCVK Model, Database, API Server)
- Akses cepat ke manajemen lainnya

### 👥 User Management
- Lihat daftar semua pengguna (702 akun)
- Filter berdasarkan: Warga, RT/RW Officer, Admin
- Lihat status user (Active/Suspended)
- Cari user dengan search bar

### 📈 ML Analytics
- Monitor performa model PCVK
- Lihat akurasi per kategori produk
- Analisa distribusi deteksi
- Lihat deteksi terbaru real-time

### 👤 Profil Admin
- Lihat informasi profil admin
- Akses pengaturan akun
- Toggle dark mode
- Logout dari sistem

## Tips Penggunaan

- **Navigasi Cepat**: Gunakan bottom navigation bar untuk berpindah antar tab
- **Quick Access**: Klik card di dashboard untuk akses langsung ke fitur tertentu
- **Monitoring**: Dashboard diperbarui secara real-time (akan diintegrasikan dengan backend)
